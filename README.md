
# 🛡️ CyberShield – AI-Powered Cybersecurity Incident Management System

## 📌 Project Overview

CyberShield is a cybersecurity incident management platform developed using Python Flask and SQLite. It helps organizations and individuals report, track, analyze, and manage cybersecurity incidents through an interactive dashboard.

The system includes user authentication, incident reporting, analytics, AI-powered security assistance, risk assessment, and PDF report generation.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/GOWTHAM9968/CyberShield.git
```

### Move into Project

```bash
cd CyberShield
```

### Install Dependencies

```bash
pip install flask
pip install werkzeug
pip install reportlab
```

### Run Application

```bash
python app.py
```
